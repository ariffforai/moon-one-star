## Entry

> 1/5 stars. Vanishes for two weeks a month, comes back half-lit, and still expects me to howl. Rude.

`main.ts` (Node 22, stdlib only, deterministic) writes that single line — 99 characters, 99 bytes, no trailing newline — to `/output/entry.txt`, with a loud gate that fails if the line ever falls outside the 1–120 character range, is not pure printable ASCII, or is not a single line.

## Run

```sh
node main.ts
```
